* The 4 declined are the spec's lambda re-render cases (lambdas row above). moose-stash never re-parses a lambda's return value as a template — doing so would let user text returned from a lambda become live tags like {{secret}} or {{> admin}}, a server-side template-injection surface — so it emits the safe literal output by design instead of expanding the returned tags. They are declines, not failures: the engine still produces correct, safe text. (mustache.js 4.2 doesn't implement these either — it passes 2 of the 10 lambda cases.)
